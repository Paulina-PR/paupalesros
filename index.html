CSS Layouts

Organización visual y la distribución de los elementos de una página web (como la cabecera, el menú, el contenido principal y el pie de página) dentro de la ventana del navegador.

Animaciones

Son efectos visuales que permiten cambiar las propiedades de un elemento HTML (como su color, tamaño, posición o rotación) a lo largo del tiempo de forma fluida y sin necesidad de usar JavaScript.

Sass

(Syntactically Awesome Style Sheets) es un preprocesador CSS que extiende las capacidades del CSS tradicional al añadir características avanzadas de programación.

¿Qué es CSS?

CSS (por sus siglas en inglés, Cascading Style Sheets, o Hojas de Estilo en Cascada) es un lenguaje de diseño gráfico que se utiliza para definir y crear el aspecto visual de un documento escrito en HTML o XML. CSS no es un lenguaje de programación, ya que no cuenta con lógica de programación, condicionales ni bucles. Es un lenguaje declarativo de estilos

¿Qué aprenderé en este curso?

Aprenderas a diseñar, dar color, organizar y embellecer las páginas web.

¿Qué es CSS GRID?

Sistema de maquetación en dos dimensiones (filas y columnas) para la web que permite organizar y posicionar elementos de forma sencilla, flexible y adaptable.
